# T7TT: 철권 7을 태그 토너먼트 2처럼 (테스트 버전 0.1.1)

철권 7(Steam)에서 캐릭터 두 명을 골라 태그, 태그 콤보, 태그 어썰트를 쓸 수 있게 하는 **오프라인 전용** 비공식 모드입니다.
목표는 "태그 2 해 본 사람이 어색하지 않은 태그"입니다. 태그 2를 잘 아시는 분의 피드백을 받고 싶습니다.

> **연습 모드에서만 테스트해 주세요.** 다른 모드는 충분히 확인하지 못했습니다.

## 설치

1. [Releases](../../releases)에서 `T7TT_v0.1.1.zip`을 받아 압축을 풉니다.
2. `T7TT.exe`를 실행하고 **설치 / 적용**을 누릅니다.
   처음 한 번 캐릭터 데이터를 만듭니다. 1분 정도 걸리고 약 550MB를 씁니다.
3. **게임 실행**을 누릅니다.

- 철권 7은 자동으로 찾습니다. 설치할 때 게임은 꺼 두세요.
- 서명이 없는 프로그램이라 Windows가 경고할 수 있습니다. 백신이 막을 수도 있습니다.
- **제거** 버튼을 누르면 모드 파일을 지우고, 바꾼 게임 설정을 설치 전으로 되돌립니다.

## 조작

| | 키보드 | 패드 / 스틱 (XInput) |
|---|---|---|
| 태그 | Space | LB |
| 문제 장면 기록 | F8 | F8 (키보드) |

태그 키는 런처에서 바꿀 수 있습니다. 패드·스틱은 XInput으로 잡히는 것만 됩니다(PS 패드는 Steam 입력을 켜세요).

**캐릭터 선택**: 왼쪽(TAG) → 결정 → 메인 결정 → 파트너 결정.
의상을 고르려면 캐릭터에 커서를 두고 U(패드 X)를 누른 뒤 목록에서 결정합니다. 메인과 파트너 모두 커스텀을 입을 수 있습니다.

**태그**

| 상황 | 결과 |
|---|---|
| 서 있을 때 | 그냥 태그. 버튼 기술은 0.75초, 가드는 1초 뒤부터 |
| 띄우는 기술 중 | 태그 콤보 |
| 상대가 스크류에 맞은 순간 | 태그 어썰트 |
| 어썰트 중 | 파트너 공격이 끝난 뒤 메인으로 복귀 |
| 던지기 성공 중 | 태그 던지기 |
| 다운 중 | 일어나며 교대. 파트너 레이지(또는 체력 40% 이하)면 오른손과 함께 태그 크래시 |

대기 캐릭터는 빨간 체력을 회복하고, 한 명이라도 KO되면 라운드를 집니다. 레이지 아츠는 꺼져 있습니다(런처에서 켤 수 있음).

## 피드백 부탁드립니다

1. 이상한 장면이 나오면 바로 **F8**을 누릅니다. 직전 15초가 기록됩니다.
2. 런처의 **피드백 파일 만들기**를 누르면 바탕화면에 zip이 생깁니다.
3. **무엇을 했고, 무엇이 나왔고, 태그 2라면 어땠을지** 한 줄과 함께 보내 주세요. [Issues](../../issues)에 올리셔도 됩니다.

zip에는 F8 기록(기술 이름, 위치, 누른 키), 모드 로그, 모드 설정만 들어갑니다.

특히 궁금한 것:

- 어썰트: 파트너가 들어오는 속도와 위치, 이어지는 느낌, 메인이 돌아오는 타이밍
- 태그 콤보: 파트너가 원래 캐릭터 자리에서 나옵니다. 태그 2처럼 뒤에서 뛰어 들어오는 게 나을까요?
- 그냥 태그의 빈틈이 태그 2와 비교해 긴지 짧은지
- 타격감, 소리, 슬로우
- 태그 2에는 있는데 빠진 것

## 알려진 한계

- 엔진이 두 명만 싸우게 되어 있어, 나가는 캐릭터는 **보이기만 합니다**(공격 판정 없음).
- 어썰트 뒤 바닥까지 기다리면 상대가 멀어집니다. 태그로 일찍 돌아오면 가깝습니다.
- 파트너 커스텀의 안경·무기 같은 소품은 아직 안 보입니다.
- 데빌 진과 헤이하치 위주로 확인했습니다. 다른 캐릭터, P2 쪽 태그 팀, 대전 모드는 확인이 부족합니다.
- 온라인에서는 꺼집니다. 온라인에서 쓰지 마세요.

## 소스와 직접 빌드

GPL-3.0으로 공개합니다(LICENSE). 구성:

- `src/` 게임에 들어가는 모드 본체 (`dinput8.dll`)
- `launcher/` 런처
- `tools/` 설치된 게임에서 태그용 캐릭터 데이터를 만드는 코드
- `tests/` 오프라인 테스트

빌드 순서 (Windows, Visual Studio Build Tools, Python 3 + pycryptodome):

1. `build.bat` → `bin\dinput8.dll`
2. 캐릭터 데이터 만들기:
   `set T7TT_TKDATA=<철권 7 폴더>\TekkenGame\Content\Binary	kdata.bin` 후 `python toolsuild_partner.py bin\T7Tag_partners`
3. `build_tests.bat` → `bin	ag_harness.exe` (2번 데이터 필요)
4. 런처 실행: `python launcher\T7TT.pyw`

게임 데이터를 여는 데 필요한 값은 이 저장소에 없습니다. 실행할 때 설치된 게임에서 읽습니다.
